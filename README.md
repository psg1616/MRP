# MRP
정말 예리한 질문입니다! 처음 MRP 수식을 접할 때 실무자들도 가장 많이 헷갈리는 부분이에요.

결론부터 말씀드리면, **안전재고 200개 분량도 발주에 포함시켜서 계산하는 것이 맞습니다.**

그 이유는 재고를 계산할 때 '지금 당장'의 기준이 아니라, **'생산이 모두 끝난 직후'의 창고 상태**를 기준으로 봐야 하기 때문입니다. 흐름을 따라가며 직관적으로 설명해 드릴게요.

### 📦 A-001 재고 시뮬레이션

* **현재 상태:** 창고에 300개가 있습니다.
* **생산 투입:** 공장에서 1,000개를 달라고 합니다.

만약 질문자님 말씀대로 안전재고를 무시하고 **단순 부족분인 700개만 딱 맞춰서 사온다면** 어떻게 될까요?

1. 기존 재고 300개 + 새로 사온 700개 = 총 1,000개가 모입니다.
2. 이 1,000개를 생산 라인에 전부 투입합니다.
3. **생산 종료 후 창고 재고 = 0개**

### 🛡️ 안전재고의 진짜 의미

안전재고(200개)는 "창고에 이 정도는 있으니까 안심해도 돼"라는 뜻이 아니라, 갑자기 불량이 터지거나 다음 발주가 지연되는 등 비상 상황을 대비해 "무슨 일이 있어도 창고 바닥에 항상 깔려 있어야 하는 절대 보존 수량"을 뜻합니다.

즉, 생산이 다 끝난 후에도 창고에 최소 200개는 남아있게 만들어야 합니다.

* 순수하게 부족한 수량: 1000(필요) - 300(현재) = **700개**
* 창고에 남겨둬야 할 보존 수량: **200개**
* **최종 순소요량:** 700개 + 200개 = **900개**

따라서 지금 당장 창고에 안전재고(200개)보다 많은 수량(300개)이 있더라도, 그 300개는 곧 생산 라인으로 전부 빨려 들어갈 물량이기 때문에, 보존용 안전재고 200개를 얹어서 발주를 넣는 것이 올바른 자재 계획(MRP) 로직입니다.
